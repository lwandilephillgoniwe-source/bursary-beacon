---
name: Learnership source quality
description: Learnership sources must contain a current, specific intake before collection or publication.
---

Generic SETA guidance, recruitment-maintenance pages, unrelated adverts, filled vacancies, and pages without a specific closing date or application path stay discovery-only. A learnership record is not publishable merely because the programme is generally available or the source URL responds with HTTP 200.

**Why:** The initial learnership registry contained a published MERSETA demo record backed only by generic guidance, and a Sasol vacancy was already filled when audited.

**How to apply:** Require a current specific advert, explicit eligibility, a working official application path, and a reliable closing date or explicitly stated rolling intake before considering a learnership for the existing confidence/publish gate.
